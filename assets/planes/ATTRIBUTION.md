# Airplane artwork

The airplane is **not** a third-party sprite any more. It is a low-poly 3D model
built from primitives in code and rendered at runtime:

- Model, camera and lighting: `scripts/airplane/plane_model_3d.gd`
- Every airplane owns one `PlaneModel3D` (a `SubViewport` with an orthographic
  side camera), so the local pilot, the opponent and the menu's flypast each get
  their own livery.

That makes the game **2.5D**: the world, physics, hitboxes, projectiles and the
whole interface stay flat 2D, while the aircraft itself is a real 3D object seen
from the side. The camera never moves off the plane's side, so the aircraft is
always shown in profile; the 2D `Airplane` node rotates and mirrors the rendered
texture exactly as it used to rotate a sprite.

Ownership: the model is generated by this project's own code, so there is no
external licence and no attribution requirement for it.

## Earlier version

Up to the previous revision `plane_player.png` / `plane_enemy.png` were a
CC-BY 3.0 sprite ("airplan" by knik1985, https://opengameart.org/content/airplan).
Those files and that credit are gone with the switch to the 3D airframe.

Everything else in `assets/` is also drawn by this project: the cloud and fireball
sheets and the muzzle flash are generated by `tools/build_art.py`, and the
landscape props are hand-written SVG. The infantrymen are modelled in code too
(`scripts/environment/soldier_model_3d.gd`), rendered into a side view exactly
like the aircraft.
